# PL vs BARANG Checker

Versi GitHub Pages tanpa Streamlit/Python. Perbandingan dilakukan langsung di browser.

Urutan baris:
- MATERIAL CODE ↔ KODE BARANG
- ITEM NAME ↔ URAIAN
- QTY ↔ JUMLAH SATUAN
- N/W ↔ NETTO
- G/W ↔ BRUTO

Jika cocok semua: tidak ada notifikasi sukses.
Jika berbeda: tampilkan baris, field, nilai PL, nilai BARANG dan tombol download Excel.
